# NOTAM 지도 친절모드

[fly-smart-team/notammap](https://fly-smart-team.github.io/notammap/) 에 한국어 해설 레이어와 몇 가지 기능을 더한 버전입니다.
원본 기능·화면 구성·오프라인 동작은 그대로 두고, 아래를 추가했습니다.

- 😊 친절모드: 섹션별 사용 안내, NOTAM마다 한 줄 요약·내 비행과의 관계·한국시간 유효기간·고도·약어 풀이
- 🌪️ SR 4 이상 구간: 항법로그 SR 값을 읽어 이륙 후 몇 분부터 몇 분간인지 + 지도 표시
- 📍 실시간 비행기 위치: 기기 위치 서비스(블루투스 GPS 포함)로 지도에 표시, 다음 SR 구간까지 남은 시간
- 🌀 흔들림 정보 → 지도: 난기류 보고 텍스트(좌표·웨이포인트·고도·원인)를 붙여넣으면 지도에 표시
- 오프라인 캐시(service worker): 한 번 연 뒤에는 인터넷 없이도 열림

> 자동 해설은 참고용입니다. 판단은 반드시 NOTAM 원문과 회사 브리핑 자료로 하세요.
> OFP PDF는 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. (실시간 기상 조회 시 공항 코드만 외부 기상 API로 전송)
